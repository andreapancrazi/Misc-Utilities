# Misc-Utilities

Welcome to the Misc-Utilities repository! This repo houses a variety of utility scripts in PowerShell and Bash, created to assist with different administrative tasks and automations.

## Structure

The repository is organized as follows:
```
Misc-Utilities/
├── readme.md
├── powershell/
│   ├── script1/
│   │   ├── script1.ps1
│   │   └── readme.md
│   ├── script2/
│   │   ├── script2.ps1
│   │   └── readme.md
│   └── scriptN/
│       ├── scriptN.ps1
│       └── readme.md
└── bash/
    ├── script1/
    │   ├── script1.sh
    │   └── readme.md
    ├── script2/
    │   ├── script2.sh
    │   └── readme.md
    └── scriptN/
        ├── scriptN.sh
        └── readme.md
```
## Usage

Each script has its own readme with detailed usage instructions. Simply navigate to the relevant directory, follow the steps provided, and execute the script.
